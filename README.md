# 엠폰투(em ponto) 상권 분석 보고서

서울 포르투갈식 에그타르트 전문점 출점을 위한 상권 분석 보고서입니다.

- 최종 선정: 문래예술촌(문래창작촌), 진입적기 지수 84.5 (후보 281곳 중 1위, 2년 비교)
- 후보: 한강로동 땡땡거리(80.9, 2위), 충무로 영화인의거리(80.5, 3위)
- 데이터: 서울 열린데이터광장 상권분석서비스(추정매출·추정유동인구·점포), 성수 사전 검증은 휴게음식점 인허가(커피숍) 데이터
- 검증: 2013~2016년 카페 증가 지표는 성수동1가를 상위 3~13%로 포착했으나, 6지표 합산 판정식은 2021년 이후 예측력이 없었습니다.
