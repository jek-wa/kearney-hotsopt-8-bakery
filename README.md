# 엠폰투(em ponto) 상권 분석 보고서

서울 포르투갈식 에그타르트 전문점 출점을 위한 상권 분석 보고서입니다.

- 최종 선정 상권: 문래예술촌(문래창작촌), 판정식 점수 10.0 (2년 비교 기준)
- 후보: 충무로 영화인의거리(8.94), 서교동(홍대, 7.58)
- 데이터: 서울 열린데이터광장 상권분석서비스(추정매출·추정유동인구·점포), 2024Q2 대비 2026Q2
- 한계: 과거(2023Q2) 적용 검증에서 예측력이 약했고, 검색량·임대료는 대리지표를 사용했습니다.
